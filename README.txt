TIC-TAC-TOE (C LANGUAGE)

Files:
- tictactoe.c : Complete C source code
- README.txt  : Instructions

How to compile with GCC:
    gcc tictactoe.c -o tictactoe

How to run on Windows PowerShell:
    .\tictactoe.exe

How to run on Linux/macOS:
    ./tictactoe

This is a two-player console game. Player 1 uses X and Player 2 uses O.
Enter a position from 1 to 9 to place your mark.
